# AI-READONLY: 身份与目标目录

存放由用户明确确认、愿意公开的基础身份、目标和边界。此目录默认只读；任何 AI 均不得从旧聊天、设备文件或推断中自动填充。

| 文件 | 用途 |
| --- | --- |
| [profile.md](profile.md) | 称呼、职业、核心标签及公开简介 |
| [goals.md](goals.md) | 长期目标、阶段目标与衡量方式 |
| [boundaries.md](boundaries.md) | 信息公开范围与授权边界 |

填写后保留确认日期与公开范围，通过 PR 留下变更记录。未填写项保持 `{{占位符}}` 或 `unknown`，不要猜测。
