# AI-READONLY: 自动记忆事件目录

自动记录器仅能在此创建 `memory/entries/<event_id>.md`，不得覆盖或删除已有事件文件。`event_id` 应稳定且不包含姓名、邮件、私有项目名或其他敏感信息，以便在重复提交时去重。

每条记录应明确说明：记录类型、可公开内容、来源或证据、确认状态、适用范围、日期及关联记录。实际机器字段以 `archive-manifest.json` 和适配器校验规则为准。

处理流程为：提炼候选 → 检查公开范围与来源 → 去重及冲突核对 → 校验 → 独立分支与 PR → 检查和合并 → 回读。

核心身份、长期目标、任务优先级或权限规则的变化只能作为候选建议，不能因为写入本目录就自动覆盖其他目录的正式规则。此说明文件不是记忆事件，不参加事件去重。
