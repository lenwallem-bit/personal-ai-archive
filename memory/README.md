此目录保存能够复用且适合公开的记忆摘要。原始聊天、私人工作材料和未经确认的推断不自动进入仓库。

| [lessons.md](lessons.md) | 经验复盘模板 | 受审 PR |

## 记忆生命周期

新候选必须区分来源、确认程度和适用范围。`confirmed` 表示有明确支持，`candidate` 表示待确认，`superseded` 表示已被后续记录替代，`expired` 表示不再适用，`rejected` 表示不应采用。模板中的 `template` 和 `unknown` 不是有效个人事实。

同一事件只记录一次。出现矛盾时记录分歧与后续确认，不直接覆盖旧内容。自动追加记录不是自动改写身份、目标或核心规则的授权。

执行环境应先完成公开检查和内容校验，再创建分支与 PR。只有远端提交、检查及回读成功，才能报告相应同步阶段已完成。
