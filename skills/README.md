# AI-READONLY: 能力与学习目录

此目录保存个人能力档案与学习计划。这里的“技能”指人的能力记录，不是可执行 AI 插件，也不会自动给 AI 增加工具权限。

| 文件 | 用途 |
| --- | --- |
| [competencies.md](competencies.md) | 已掌握技能与证据 |
| [learning-plan.md](learning-plan.md) | 学习目标、步骤和完成标准 |
| [growth.md](growth.md) | 待提升能力与练习反馈 |

按实际作品、练习结果或用户自评填写，明确区分自评和经过验证的能力。不要把“接触过某工具”直接写成“熟练掌握”。更新通过受审 PR 留下记录。
