# AI-READONLY: 历史归档目录

此目录保存已完成项目、旧文档和任务的公开摘要及索引。归档不等于验收通过；状态必须有对应证据，私人原件保留在适当的私有位置。

| 文件 | 用途 |
| --- | --- |
| [projects.md](projects.md) | 历史项目摘要、成果与后续事项 |
| [documents.md](documents.md) | 可公开旧文档的版本与索引 |
| [completed-tasks.md](completed-tasks.md) | 已完成任务的结果与验证记录 |

仅记录公开地址或无敏感信息的引用编号，不把私有设备路径、私人文件链接或受限资料转成公开索引。归档后发现错误时通过新 PR 修正并保留历史。
